# Security Policy

This repository contains simulation software and does not operate production vehicles or networks.

Please report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. Include affected files, reproduction steps, impact, and a suggested mitigation if available. Do not publish exploit details before a fix is available.

Only the latest main-branch revision is supported. Security reports about upstream ns-3, 5G-LENA, compilers, or Python packages should also be reported to their respective maintainers.
